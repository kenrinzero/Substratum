## Findings by entry

### 1. swallowed-exceptions

**legitimate-variant (repeat)** — `substratum/verify.py:88` catches
`Exception` and returns the frozen gate's structural-red diagnostic. The
`# noqa: BLE001` cue still matches, but this is the documented normalization
trust boundary and does not substitute an empty/not-found value.

### 2. hardcoded-config-values

**legitimate-variant (repeat)** — `tests/conftest.py:89` retains a literal
two-second daemon-thread join ceiling. The numeric-literal API-call cue
matches, but the ceiling is over 80 times the documented 25 ms sampling
cadence and cannot block process exit. Runtime/seedtool timeouts, batch sizes,
memory limits, format sizes, and offsets are named constants.

### 3. missing-network-timeout

**no candidates** — scanned all `subprocess.run` and
`urllib.request.urlopen` sites; all carry a timeout. The same invariant is
AST-enforced by `tests/test_tooling_hardening.py:15-32`.

### 4. narrating-comments

**false-positive-shape (repeat)** — numbered fixture-authoring phases and the
check banners in `substratum/verify.py:82-110` match step/banner cues. They
separate independent proof phases and mirror the frozen four-check protocol,
which is the checklist's permitted phase-boundary case.

### 5. near-identical-siblings

**false-positive-shape (repeat)** — `ps1_bincue.py` and
`saturn_dc_raw.py` now share batching and BCD/MSF mechanics, but remain only
two siblings and differ materially in CUE ownership, Mode-2 XA subheaders,
mixed 2048/2324-byte payload semantics, and public sector access. A common
base would obscure format-specific refusals rather than substantially shorten
the code.

### 6. convention-drift

**real-defect (new)** — sibling filesystem normalizers diverge on the frozen
relative POSIX-path contract. `substratum/formats/xdvdfs.py:92-96` rejects
`.`, `..`, `/`, and `\` components, while
`substratum/formats/iso9660.py:80-83`,
`substratum/formats/gc_fst.py:115-116`, and
`substratum/formats/wii_u8_arc.py:67-68` concatenate decoded on-media names
without equivalent validation. The cue is sibling implementations of the
same role with divergent surface guarantees. In-memory malformed fixtures
confirmed that all three emit `../PWN`, violating
`substratum/contract.py:87` and allowing a consumer that joins an entry path
to a destination root to escape that root.

### 7. inconsistent-error-handling

**legitimate-variant (repeat)** — CHD executable discovery at
`substratum/formats/chd.py:65-94` raises `FileNotFoundError`, whereas malformed
media raises `ValueError`. The sibling-wrapper cue matches, but missing
runtime machinery and malformed input are distinct failure classes; public
normalizer failures otherwise propagate consistently.

### 8. mutable-default-arguments

**no candidates** — an AST scan found no list, dict, set, `list()`, `dict()`,
or `set()` defaults in any function signature.

### 9. assert-for-runtime-validation

**false-positive-shape (repeat)** — module-level sector-layout identities and

`substratum/formats/ps1_bincue.py:319` is cache-state type narrowing, while
the origin assertions at `ps1_bincue.py:486` and
`saturn_dc_raw.py:245` follow non-empty-sector checks and loops that
unconditionally assign a validated value. No external input relies on an
`assert` for acceptance.

### 10. async-await-mismatch

### 11. brittle-error-detection

### 12. f-string-in-logger-call

### 23. off-by-one

**false-positive-shape (repeat)** — the

### 24. wrong-tool-for-job

**no candidates (resolved repeat)** — equal verifier chunks use bulk byte

single-item fixture loops operate on small authoring fixtures or are the
format algorithm itself.

## Compound findings

The path-component convention drift affects both normalization and later
consumption: malformed names enter a `FileTree`, and the frozen verifier then
uses `reference_dir / entry.path`. The parser-side fix closes both surfaces,
so this is one entry-6 finding rather than a separate wrong-tool finding.

## Uncategorized observations

1. **ISO9660 accepts a truncated directory record.**
   `substratum/formats/iso9660.py:63-65` checks that the sliced remainder is at
   least 34 bytes and that the claimed record can hold its identifier, but
   does not require `len(rec) == rec_len`. An in-memory record with 36 actual
   bytes and a claimed length of 255 normalized successfully as file `A`.
   This is a correctness issue outside the 24-pattern taxonomy.
2. **The strict PS1 CUE parser silently accepts unsupported syntax and
   duplicate INDEX 01 lines.** `substratum/formats/ps1_bincue.py:233-246`
   overwrites a prior INDEX 01 and only rejects a selected list of unsupported
   directives; any other unmatched line falls through. The committed
   synthetic carrier normalized successfully after adding either
   `THIS IS NOT A CUE DIRECTIVE` or a second `INDEX 01 00:00:00`.
3. **GC-FST's implementation docstring is stale.**
   `substratum/formats/gc_fst.py:73-77` says the fixture is flat and nested
   proof is future work, while `tests/test_gc_fst.py:203-349` and
   `NORMALIZERS.md:20` show the nested two-party fixture and its structural
   regressions are already live.

## Suggested fix order

1. Restore the common path contract one normalizer at a time: ISO9660 first
   (it also has the independent record-boundary defect), then GC-FST, then Wii
   U8. Reject `.`, `..`, slash, and backslash components with exact structural
   tests while preserving each format's existing name encoding policy.

The ISO record-boundary check and PS1 CUE strictness are independent
fixtureless correctness units. The GC-FST docstring correction can ride with
its path-validation unit or land as a minimal documentation-only cleanup.
