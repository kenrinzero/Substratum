# fixtures/_local/ — operator drop zone (gitignored)

Retail fixture files requested via a `FIXTURE REQUEST: <platform, any
small title>` note in a NORMALIZERS.md row land here, copied by Kenrin at
his convenience. Also home for homebrew whose license doesn't permit
committing. Nothing in this directory is ever committed or published;
outputs derived from these files are metadata only (file trees, byte
ranges, headers). Record what was dropped (filename, platform, source) in
the unit's NORMALIZERS.md row when you consume it.
